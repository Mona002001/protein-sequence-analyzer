# Protein Sequence Analyzer

A Python-based bioinformatics project for analyzing protein sequences from FASTA files.

## Overview

Protein Sequence Analyzer is a command-line tool that analyzes protein sequences and calculates important physicochemical properties using Biopython.

The project generates three types of reports: TSV, HTML, and PDF.

## Features

- Read protein sequences from FASTA files.
- Validate protein sequences.
- Calculate protein sequence length.
- Calculate molecular weight.
- Calculate isoelectric point (pI).
- Calculate GRAVY (Grand Average of Hydropathicity).
- Calculate instability index.
- Calculate aromaticity.
- Calculate amino acid composition and percentages.
- Generate TSV, HTML, and PDF reports.

## Output

The program generates three reports:

- **TSV:** Tab-separated results suitable for spreadsheet applications.
- **HTML:** A formatted report that can be opened in a web browser.
- **PDF:** A printable protein analysis report.
